# REV2K Release Notes / Catatan Rilis REV2K

## Board compatibility / Kompatibilitas board

**Board V2 users: use REV2K for now.**

Current field testing on a UV-5RH Board V2 unit found REV2K working normally for APRS List, receive sensitivity, backlight behavior, and GNSS lock. Later REV2P/REV2R/REV2S builds showed regressions on that tested Board V2 unit, so they are **not currently recommended for Board V2**.

**Board V1 users:** the latest public Board V1 build is **REV2R / NUSA 2R**.

> Board V1 / Board V2 refers to the hardware/PCB revision, not the V2.0.9 firmware-family name. Hardware variants can differ, so keep the original stock firmware available for recovery.

## English

REV2K is the stable APRS packet-detail baseline and the **current known-working choice for tested Baofeng UV-5RM / UV-5RH Board V2 units** using the V2.0.9 firmware family. It retains normal FM operation and the proven APRS RX/list/detail path.

Known limitation: APRS message/SMS receive is not yet solved in REV2K.

## Bahasa Indonesia

**Pengguna Board V2: gunakan REV2K untuk saat ini.**

Pada pengujian lapangan sebuah UV-5RH Board V2, REV2K bekerja normal untuk APRS List, sensitivitas RX, backlight, dan lock GNSS. REV2P/REV2R/REV2S menunjukkan regresi pada unit Board V2 yang diuji tersebut, sehingga saat ini **tidak direkomendasikan untuk Board V2**.

**Pengguna Board V1:** rilis publik terbaru untuk Board V1 adalah **REV2R / NUSA 2R**.

REV2K tetap dipertahankan sebagai baseline stabil APRS packet-detail. Keterbatasan: penerimaan APRS Message/SMS belum selesai pada REV2K.
